# Pirate Token RP 🏴‍☠️

Um resource pack para Minecraft Java que substitui os ícones da barra de vida pela imagem original do Pirate Token.

## Resolução

- Sprites da HUD: **180×180 píxeis** (em vez dos 9×9 originais).
- Ícone do resource pack: 64×64 píxeis.
- A HUD continua a ocupar o mesmo espaço no ecrã; a resolução maior aumenta o detalhe da textura, não o tamanho dos corações.

## Compatibilidade

- Minecraft Java Edition **1.21.11 até 26.2** (pack formats 75–88).
- Inclui sprites normais, meios-corações, estados especiais, hardcore e corações de veículos.

## Instalação

1. Descarrega `Pirate-Token-RP.zip`.
2. No Minecraft, abre **Opções → Pacotes de recursos → Abrir pasta de pacotes**.
3. Copia o ZIP para essa pasta e ativa **Pirate Token RP**.

## Sobre as texturas

Os corações completos usam a imagem original fornecida, redimensionada diretamente de 512×512 para 180×180 com reamostragem de alta qualidade. Os meios-corações são um corte vertical da metade esquerda da mesma imagem, numa tela transparente de 180×180. Não há redesenho nem recoloração. Os contentores de corações vazios são transparentes.

Este pack altera apenas as texturas dos corações/ícones de vida, não as mecânicas do jogo.
